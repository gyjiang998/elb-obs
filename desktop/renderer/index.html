连接演示说明
内置演示客户端会调用远程工具执行 pwd、uname 与 ls，用于验证接入链路。它是连接测试客户端，不是 AI Agent。

      

      

        
失败自动重试与操作授权
对已接入恢复合同的步骤，工作台可以将脱敏错误自动发送给 Code Agent；助手完成修复并回传结果后，工作台只重试原来失败的步骤一次。

        
        
        
        
这些授权只约束工作台发起的无人值守恢复任务和 desktop-ssh 工具；用户亲自点击的操作仍按本次明确指令执行。
