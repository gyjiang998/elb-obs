# 自建 API 知识库

- 先确认异构单元和 Source Connector；未登记路径先通过页面 action 登记，不猜 connector ID。
- 目标是调用方可消费的 API 合同。优先公开 SDK/NDK 头、算子/格式/能力枚举、IDL/HDI/VDI 和导出接口；Service/Manager/Builder 等内部实现只作补充证据。
- 调用 `knowledge_build_custom_api_kb` 完成有界扫描。同名单元每次创建独立“自建”资产，不覆盖旧库，也不合并平台内置库。
- 检查 quality、公开合同/算子/内部实现计数及截断、超时和扫描范围。内部实现占主导或证据不足时如实报告，并建议更聚焦的接口目录。
- 最终给出库名、kb_id、源码快照、记录分类、扫描边界和 `developer_only` 合并策略。不要把静态候选描述成设备支持、公开 SDK 审核或性能证明。
