# 代码知识分析

围绕用户选择的源码范围形成可追溯、可检索、可继续修订的 Markdown 报告。

1. 读取任务中的 `graph_id`、源码范围和快照，调用 `code_graph_get` 确认底图状态与绑定范围。
2. 使用 `code_graph_query_knowledge` 围绕模块职责、入口、关键流程、状态与数据、调用关系和 HiTrace 候选做查询。
3. 报告至少覆盖：分析范围与快照、模块职责、关键接口、控制流与数据流、重要调用关系、HiTrace 候选、证据边界和待确认问题。需要表达流程或关系时可加入 Mermaid。
4. 分别标注平台底图候选、已读取源码事实、Agent 语义归纳和运行时待验证项。静态调用关系作为源码导航与设计分析证据，运行时路径和耗时由 Trace 或采样数据确认。
5. 首份报告调用 `code_graph_publish_report` 发布。继续修改时读取父报告，只重查受问题影响的范围，并通过 `parent_report_artifact_id` 保留版本血缘。

优先交付覆盖用户目标的最小完整报告，再根据追问扩展细节。
