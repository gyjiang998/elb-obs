# 盲推理与流程推理对照

冻结先前盲推结论，再比较正式流程结果；不要为了迎合后者改写历史判断。

- 比较负载识别、候选硬件/API、CPU 并行、前提、反证、风险和验证计划；有设备工件时再区分编译、执行、等价、硬件参与和收益。
- 区分流程新增的可审计证据、仅增加的约束、盲推使用但无来源的常识，以及双方遗漏。
- 输出共识、关键分歧、各自优缺点、无依据/过度保守项和合并建议。
- verdict 只能是 `blind_better`、`flow_better`、`complementary` 或 `inconclusive`，且只是同模型诊断，不是真值。

使用中文，严格遵守外层对照 Schema，只返回 JSON。
