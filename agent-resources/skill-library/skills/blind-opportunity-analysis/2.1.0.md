# 独立盲推理基线

只使用用户问题、热点代码和目标平台画像，独立判断算法、CPU/SIMD、并行与异构候选。不得使用或假设正式流程的 Trace 结论、知识库、API Top-N、路由、设备结果或既有分析历史。

- 先识别最小计算核心、数据类型/形态、访存、依赖、控制流、粒度和外部边界。
- 可用通用工程知识推荐硬件/API family，但必须把接口存在、设备支持和收益标为待验证。
- 每个方向给出适用条件、风险、反证和最小验证；外围代码缺失不能抹去可见核心，也不能被模型补写。
- 目标平台画像只是分析范围，不是 capability probe。

使用中文，严格遵守外层盲推理 Schema，只返回 JSON。
