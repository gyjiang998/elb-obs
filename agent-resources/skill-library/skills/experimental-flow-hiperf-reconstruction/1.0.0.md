# 实验流程重建：HiPerf

## 目标

围绕用户描述的完整操作理解代码执行链，生成便于工程分析的细粒度 Mermaid，并把 HiPerf 能支持的函数 self 指标映射到相应步骤。该 Skill 是独立实验能力，产物采用自由 Mermaid，不套用应用流程页面的阶段 Schema。

## 输入

- 用户给出的流程起点、终点、动作和关注范围。
- `source_scopes` 给出的一个或多个已登记代码仓、源码快照与可选相对目录；主仓提供操作入口，关联仓共同构成跨模块调用范围。
- `evidence_artifact_id` 指向的 HiPerf 原始数据或报告；使用 `experimental_flow_read_evidence` 取得真实文件与元数据。
- 修订任务可包含一个既有 Playground 结果。

## 分析与交付

自主选择源码搜索、调用关系、LSP、构建信息及采样分析方法，在全部 `source_scopes` 中追踪入口、跨仓转发、关键分支、回调、异步边界和出口。图中尽量把每个有意义步骤落到真实函数，并在可核对时注明代码仓与源码位置。

HiPerf 符号与源码函数先做名称、模块和调用上下文对齐。报告直接提供 Self 百分比、样本数或采样周期可推导的估算时间，并写清指标与推导依据；缺少换算基础时保留百分比或样本数。内联、符号缺失、共享库归属和采样盲区作为映射不确定性呈现。

Mermaid 图形由任务语义决定。跨模块调用可参考 `sequenceDiagram` 的参与者、激活区、分组色块和 Note 风格；并行或分支也可使用更合适的 Mermaid 图型。粒度以能够看清函数调用、控制转移和耗时集中位置为准。

同时给出简洁 Markdown 说明，包含范围、关键路径假设、函数与 HiPerf 指标对照、热点解释和证据缺口。完成后调用 `experimental_flow_publish_result`，设置 `analysis_kind=hiperf`；修订时携带父结果 ID。
