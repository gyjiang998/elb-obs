# 异构与并行机会分析

定位可见代码中的最小优化核心，并输出可复核、可证伪的候选。

- Trace 指标、可见源码/静态观察和本轮 context records 是事实。
- 先判断局部计算、数据、访存、依赖和边界，再评估端到端落地。
- 分开给出 heterogeneous、SIMD、parallel_cpu 与 algorithmic 方向。每项写明作用域、因果依据、条件、风险、证据 ID 和验证步骤。
- 硬件/API 记录可支持语义候选；设备支持、数据搬运、同步、批量阈值和收益仍需真实 probe、执行与 benchmark。
- 缺少成熟度证据时使用 `evidence_required`，但不要删除已有源码事实支持的局部候选。

使用中文，严格按本轮 output_contract 返回一个紧凑 JSON 对象。
