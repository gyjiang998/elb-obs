# 代码上下文检索

平台代码底图是快速导航和候选生成能力；Agent 原生工具支持开放探索，真实源码与编译上下文用于形成静态结论。

1. 从任务上下文取得源码范围、快照、用户目标以及 Trace event、文件、符号或类型等已有线索。
2. 任务携带 `graph_id` 时用 `code_graph_get` 读取底图范围、快照和可查询状态。与当前快照匹配的 ready 底图可用于快速定位入口、caller/callee、数据对象、完成边界和 HiTrace 候选。
3. Agent 按线索强度和检索效果组合 `code_graph_query_knowledge`、原生搜索、LSP、Tree-sitter、Clang/编译上下文和源码阅读。直接路径或符号可直达源码；底图候选可引导小范围复核；召回不足时扩展查询和跨仓探索。
4. 读取决定结论的定义与调用点，确认参数、返回值、分支、数据流、生命周期、动态分派和跨模块关系。
5. 将底图未命中解释为索引状态，将底图边解释为待复核候选。新发现的符号、关系和模块边界可作为后续底图增量更新的输入。
6. 向后续任务提供源码引用、已确认关系、静态候选、开放问题和下一步取证建议，并保持源码快照与查询血缘。

应用流程以完整用户操作和入口/完成边界为检索种子；Trace 热点以事件、包围函数及 caller/callee 为种子；API 追踪以接口族、声明和实现符号为种子。
