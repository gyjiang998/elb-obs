# 代码上下文检索

把代码底图用于快速定位，把真实源码用于形成结论。

1. 从任务上下文取得 `graph_id`、源码范围、快照和用户目标；调用 `code_graph_get` 确认底图可查询。
2. 将目标拆成入口、核心符号、相邻调用、状态或数据对象、完成边界和 HiTrace 候选等检索问题，通过 `code_graph_query_knowledge` 获取限幅结果。
3. 根据首轮结果补充少量同义词、类型名或调用方向查询，使候选范围逐步收敛到与任务直接相关的文件和符号。
4. 使用 Agent 原生源码工具读取关键定义与调用点，确认参数、返回值、分支、数据流、生命周期和跨模块关系。
5. 向后续任务提供源码引用、已确认关系、静态候选、开放问题和下一步取证建议，并保持源码快照与查询血缘。

应用流程以完整用户操作和入口/完成边界为检索种子；Trace 热点以事件、包围函数及 caller/callee 为种子；API 追踪以接口族、声明和实现符号为种子。
